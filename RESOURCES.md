# Recursos de Introducción al Análisis de Datos

Fuentes de confianza para este curso. El conocimiento de las lecciones sale de aquí, no de memoria paramétrica.

## Knowledge

- [Book: *An Introduction to Statistical Learning* (James, Witten, Hastie, Tibshirani)](https://www.statlearning.com/)
  Texto base del programa. Use for: regresión, clasificación, selección de variables, regularización, clustering.
- [Book: *Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow* (Géron)](https://www.oreilly.com/library/view/hands-on-machine-learning/9781098125967/)
  Use for: flujo ML con scikit-learn, validación, árboles, bosques, boosting, SVM.
- [Book: *Python for Data Analysis* (McKinney)](https://wesmckinney.com/book/)
  Use for: pandas, limpieza, wrangling, EDA sobre `ToyotaCorolla.csv`.
- [Book: *R for Data Science* (Wickham & Grolemund)](https://r4ds.hadley.nz/)
  Solo como contraste conceptual. Use for: ideas de tidy data y visualización. No genera código del curso.
- [Book: *The Elements of Statistical Learning* (Hastie, Tibshirani, Friedman)](https://hastie.su.domains/ElemStatLearn/)
  Use for: fundamento teórico de Lasso/Ridge, árboles, boosting.
- [Book: *Applied Predictive Modeling* (Kuhn & Johnson)](http://appliedpredictivemodeling.com/)
  Use for: preprocesamiento, imputación, selección, remuestreo.
- [Book: *Data Science for Business* (Provost & Fawcett)](https://www.oreilly.com/library/view/data-science-for/9781449374273/)
  Use for: encuadre de negocio (precio de autos) y pensamiento analítico.
- [Book: *Introduction to Data Mining* (Tan, Steinbach, Kumar)](https://www-users.cs.umn.edu/~kumar001/dmbook/)
  Use for: outliers, asociación/Apriori, clustering, evaluación.
- [Book: *Forecasting: Principles and Practice* (Hyndman & Athanasopoulos)](https://otexts.com/fpp3/)
  Use for: contexto de series si alguna lección lo roza. No es foco.
- [Book: *Fundamentals of Data Visualization* (Wilke)](https://clauswilke.com/dataviz/)
  Use for: principios, color, foco/contexto (Unidad 3).
- [Book: *The Truthful Art* (Cairo)](https://www.thefunctionalart.com/p/the-truthful-art-book.html)
  Use for: storytelling y honestidad visual.
- [Docs: pandas](https://pandas.pydata.org/docs/)
  Use for: sintaxis exacta de limpieza/agrupación.
- [Docs: matplotlib](https://matplotlib.org/stable/index.html)
  Use for: figuras base generadas por script.
- [Docs: seaborn](https://seaborn.pydata.org/)
  Use for: boxplot, histogramas, pairplot, diagnósticos.
- [Docs: statsmodels](https://www.statsmodels.org/stable/index.html)
  Use for: OLS, `summary()` con AIC/BIC, QQ, partial regression (patrón del notebook ejemplo).
- [Docs: scikit-learn](https://scikit-learn.org/stable/)
  Use for: imputación, Lasso/Ridge, KMeans/DBSCAN, clasificación, PCA.

## Wisdom (Communities)

- [Cross Validated (Stack Exchange)](https://stats.stackexchange.com/)
  Comunidad moderada de estadística/ML. Use for: dudas de modelado y validación.
- [r/datascience](https://www.reddit.com/r/datascience/)
  Use for: criterio aplicado y revisión de enfoques (con filtro crítico).
